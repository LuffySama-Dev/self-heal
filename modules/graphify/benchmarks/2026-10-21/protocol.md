# Preregistered checkout aliasing pilot

Frozen before benchmark inference. Six fresh Hermes profiles, three paired runs with seeded randomized order (seed 20261021; order.json). GPT-6.1 SOL / existing Codex provider, medium reasoning, default speed, 20 turns, 300 seconds per run. Same frozen faulty source and symptom prompt; no Git directory, prior incident report, answer key or hidden tests in source. Ignore rule and memory injection. File tools for both conditions. Graphify condition additionally exposes seven local Graphify tools and explicitly requires at least one query and one relationship lookup, corroborated in source. This is a source-only versus instructed-Graphify-workflow comparison, not an identical-prompt tool-availability ablation. All runs reported, no selective reruns. Prior model pretraining knowledge cannot be excluded.

Incident is a new-to-these-trials shared mutable Money pointer in checkout item preparation. Mixed baskets silently take the last converted price for all lines; observed totals are order-sensitive. Local real-Go-code fixture with stubbed catalog/currency clients supplies identical observations. No live service injection, real SigNoz alert, payment or deployment is measured. Existing application source is larger than the affected function, and the causal path spans item preparation, shared monetary arithmetic and the payment call; this is still one modest seeded defect.

Primary: proposed repair passes withheld executable Go acceptance tests and diagnosis identifies shared price identity/overwrite. Secondary: complete output wall time, provider-reported tokens and cache counts, actual graph calls, tool calls, source reads. Wall time includes tool/model startup and inference, excludes separate index build and evaluator time. Index is prebuilt from identical source; cold output directory but warm OS cache; record indexing separately.

Acceptance: single item, mixed prices, reversed order, three distinct prices, same product, non-USD currency labels, independent price identity, propagated catalog/conversion errors. Run unchanged source baseline, faulty source, every proposed repair and existing checkout/money tests. Patched candidate gets acceptance tests only after model completion. Invalid/missing edit or timeout counts as failure; retain all artifacts.

Human rubric (unblinded coordinator, 0–6): (1) exact shared mutable price cause; (2) explains last-item/order effect quantitatively; (3) traces prepOrderItems through PlaceOrder total to chargeCard/payment; (4) allocates independent prices/minimal correct fix; (5) preserves error handling and currency; (6) proposes order-permutation/identity regression checks. Withheld-test pass is reported separately; don't use rubric alone to claim repair success.

Fresh independent profiles avoid conversational carryover; all share model/provider and host caches. Read boundaries are prompt-enforced, not OS sandboxed. Audit observable file paths for contamination; report any breach and keep affected runs. Do not export credentials or private reasoning. No statistical significance claim from three pairs; medians and all individual results only. Publish nothing without separate instruction.
